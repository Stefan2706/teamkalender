# TeamKalender – Kurzhandbuch für Unternehmen

## 1. Voraussetzungen
- Thunderbird 128 oder neuer, für Unternehmen empfohlen: **ESR-Version**
- Kalender auf einem CalDAV-Server, z. B. **Nextcloud** oder **Mailcow/SOGo**
- Exchange-Kalender werden von Thunderbird derzeit nicht unterstützt

## 2. Kalender freigeben
**Nextcloud:** Kalender-App → beim Kalender auf „⋯“ → *Teilen* → Person oder
Gruppe eintragen, Leserecht oder Schreibrecht wählen.
**Mailcow/SOGo:** Webmail → Kalender → Rechtsklick auf den Kalender →
*Freigabe* → Benutzer hinzufügen und Rechte festlegen.

Tipp: Für Vertraulichkeit nur Lesen freigeben; private Termine werden in
TeamKalender bei Kollegen nur als „Privat“ angezeigt.

## 3. Räume einrichten
**Nextcloud:** Je Raum einen Kalender anlegen (z. B. „Besprechungsraum 1“) und
für alle Mitarbeitenden mit Schreibrecht freigeben. Für automatische Zu- und
Absagen kann die Nextcloud-App „Calendar Resource Management“ genutzt werden.
**Mailcow/SOGo:** Je Raum ein eigenes Konto anlegen und dessen Kalender
freigeben.

## 4. TeamKalender einrichten
1. Add-on installieren (siehe README).
2. *Kalender auswählen* → „＋ Kalender hinzufügen“ → Server und Zugangsdaten
   eingeben → freigegebene Kalender der Kollegen und Räume anhaken.
3. *⚙ Einstellungen* → bei jedem Kalender die Art festlegen:
   **Eigener**, **Kollege** oder **Raum**.
4. Arbeitszeit, Arbeitstage und Standarddauer anpassen.
5. Häufige Zusammenstellungen als **Gruppe** speichern, z. B. „Team Vertrieb“.

## 5. Bedienung auf einen Blick
| Aktion | So geht’s |
|---|---|
| Termin-Vorschau | Klick auf den Termin |
| Termin öffnen | Doppelklick |
| Neuer Termin | Klick auf freie Fläche oder Zeitraum aufziehen |
| Verschieben / Kopieren | Ziehen / Strg + Ziehen |
| Dauer ändern | Unteren (im Zeitplan: rechten) Rand ziehen |
| Menü | Rechtsklick |
| Löschen | Entf |
| Rückgängig / Wiederholen | Strg + Z / Strg + Y |
| Heute, blättern, Ansicht | T, ← →, 1–4 |
| Einzelne Tage | Monatskalender, Strg + Klick |

## 6. Kategorien
Kategorien mit Farben werden in Thunderbird gepflegt: *Einstellungen →
Kalender → Kategorien*. Zuweisen per Rechtsklick auf einen Termin.

## 7. Updates und Support
Updates installieren sich automatisch beim Thunderbird-Neustart.
Fehler melden: *⚙ Einstellungen → Fehler melden* oder stefan@ts-scherer.com.
