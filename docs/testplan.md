# Testplan für Beta-Tester

Bitte mit **Testterminen** in einem **Testkalender** prüfen. Ergebnis jeweils
abhaken oder Fehler als GitHub-Issue melden.

## Installation & Grundlagen
- [ ] Installation aus Datei klappt, TeamKalender erscheint in der linken Leiste
- [ ] Ansicht öffnet ohne Adressleiste, Beta-Hinweis erscheint einmalig
- [ ] Kalender auswählen, Reihenfolge ändern, Gruppe speichern und laden

## Ansichten
- [ ] Tag, Arbeitswoche, Woche, Zeitplan (Tasten 1–4)
- [ ] Überlagern ein/aus, Zielkalender in der Legende wechseln
- [ ] Monatskalender: Kalenderwoche anklicken, Strg + Klick auf einzelne Tage
- [ ] Ganztägige Termine, Serientermine, kurze Termine (15/30 Min.) korrekt

## Termine bearbeiten
- [ ] Klick zeigt Vorschau, Doppelklick öffnet Thunderbird-Dialog
- [ ] Neuer Termin per Klick und per Zeitraum-Aufziehen
- [ ] Verschieben (auch in anderen Kalender), Dauer ändern, Strg + Ziehen kopiert
- [ ] Besprechung verschieben: Teilnehmer erhalten Aktualisierung
- [ ] Serientermin verschieben: nur dieses Vorkommen ändert sich
- [ ] Rechtsklick: Anzeigen als, Kategorie, Privat, Löschen
- [ ] Entf löscht, bei Serien erscheint die Nachfrage
- [ ] Strg + Z / Strg + Y machen Änderungen rückgängig bzw. wieder

## Team & Räume
- [ ] Kollegen-Kalender über „＋ Kalender hinzufügen“ einbinden
- [ ] Private Termine von „Kollegen“ erscheinen nur als „Privat“
- [ ] Raumkalender als „Raum“ markieren, Zeitplan zeigt Abschnitt „Räume“
- [ ] Freie Zeit finden mit und ohne Raum, „Anlegen“ mit Raumreservierung

## Design
- [ ] Outlook-Design im Thunderbird-Kalender (Woche, Monat), ein/aus
- [ ] Farbintensität Dezent/Mittel/Vollfarbe, Einfärben nach Kategorie/Kalender
- [ ] Helles und dunkles Thunderbird-Design

**Bitte bei Fehlern angeben:** Thunderbird-Version, TeamKalender-Version,
Kalenderserver, Betriebssystem, Schritte zum Nachstellen.
